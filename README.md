# Customer Churn Prediction

A Machine Learning project that predicts customer churn using trained models and an interactive Streamlit web application.

## 🚀 Live Demo

[Try the App](https://customer-churn---prediction.streamlit.app/)

## 🛠️ Technologies
- Python
- Pandas & NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Jupyter Notebook

## 🤖 Models
- Random Forest
- XGBoost

## ✨ Features
- Single customer churn prediction
- Batch predictions using CSV files
- Churn risk assessment
- Model insights

## ⚙️ Run Locally

```bash
git clone https://github.com/youssef170706/Customer-Churn-Prediction.git
cd Customer-Churn-Prediction
pip install -r requirements.txt
streamlit run App.py
```
